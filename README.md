# two-point-five-d-info

A CLI tool that combines PNG image layers and produces a JSON height map. Each unique color in the composite is assigned a height value based on its perceptual luminance (brighter = taller).

The output JSON is designed as input for [twoPointFiveD](https://github.com/dduxx/twoPointFiveD), an OpenSCAD library that converts pixel grids and height maps into 3D-printable models.

This project supports multiple image layers, cropping image layers, and reducing the number of distinct colors in the image to make the height maps more managable.

## Installation

First clone the repository:
```base
git clone https://github.com/dduxx/two-point-five-d-info
cd two-point-five-d-info
```

### Option 1: Install in a virtual environment (recommended)

```bash
# Create and activate a pyenv virtual environment
pyenv virtualenv 3.13 two-point-five-d-info
pyenv activate two-point-five-d-info

# Install the project
pip install -e .
```

### Option 2: Install globally

```bash
# Install the project system wide
pip install -e .
```

## Usage

```bash
2point5dinfo -l bottom.png:x1,y1,x2,y2 -l top.png:x1,y1,x2,y2 -o output.json
```

Layers are alpha-composited bottom-to-top in the order given.

Each layer may also specify optional pad and shift suffixes, applied in order crop -> pad -> shift:

- `#<x>,<y>` pads the layer symmetrically (content centered): `#32,32` adds 32 total pixels to each axis, splitting evenly across both sides (an odd pixel lands bottom/right). Values are magnitude-only, so `#-32` behaves like `#32`.
- `@<x>,<y>` shifts the layer: a positive `x` shifts right, a negative `x` shifts left; a positive `y` shifts down, a negative `y` shifts up. Dropped rows/columns are replaced with fully transparent pixels. A single value (`@x`) shifts horizontally only.

Both suffixes are optional and independent; omit either when not needed.

```bash
2point5dinfo -l bottom.png -l top.png@-3 -l overlay.png#32,32@0,2 -o output.json
```

### Options

| Flag | Description | Default |
|------|-------------|---------|
| `-l`/`--layer` | Image path, optionally with crop, pad and shift: `path[:left,upper,right,lower][#x,y][@x,y]` | (required, repeatable) |
| `-o`/`--output` | Path for the output JSON file | (required) |
| `-p`/`--pixel-height` | Starting height for the darkest color | `3.0` |
| `-s`/`--pixel-step` | Height increment between each brightness rank | `0.5` |
| `-sa`/`--skip-zero-alpha` | Replace fully transparent pixels with `null` in the output | `false` |
| `-ro`/`--reverse-order` | Sort height_map by descending brightness | `false` |
| `-mc`/`--max-colors` | Reduce the composite to at most this many unique colors | unlimited |

## Output Format

```json
{
  "image": [
    ["#ff0000", "#00ff00", "#7f0080"],
    ["#ff0000", "#00ff00", "#7f0080"],
    ["#7f0080", "#ff0000", "#00ff00"]
  ],
  "height_map": {
    "#7f0080": 3.0,
    "#ff0000": 3.5,
    "#00ff00": 4.0
  }
}
```

## Companion Library

This tool generates JSON for use with [twoPointFiveD](https://github.com/dduxx/twoPointFiveD), an OpenSCAD library that extrudes each color to its corresponding Z height, producing a 3D model suitable for printing.

Example OpenSCAD usage:

```openscad
include <two_point_five_d.scad>

// Load the JSON generated by 2point5dinfo
data = import("output.json");
two_point_five_d(data["image"], data["height_map"], pixel_size = 3);
```
